# Cloud ex Machina

> Cloud ex Machina (CxM) builds Dex, an agentic AI teammate for cloud cost and governance
> management. Dex continuously maps AWS, Azure, GCP and Kubernetes estates read-only and
> agentless, infers who owns each resource by keeping the cloud connected to the organization's
> people and code, investigates cost and governance findings, and delivers review-ready
> remediation — pull requests, scripts and CLI instructions — to the engineer who can act.
>
> This file was GENERATED by API Evangelist from the public Cloud ex Machina surface on
> 2026-08-17. Cloud ex Machina does not publish its own /llms.txt: docs.cloudexmachina.io/llms.txt
> returns the Docusaurus HTML shell with HTTP 200, and www.cloudexmachina.io/llms.txt returns 404.

## No public API

Cloud ex Machina publishes **no public REST API, GraphQL endpoint, MCP server, agent card or
machine-readable specification.** An agent cannot call this company programmatically. This was
established on 2026-08-17 by probing every host — www, docs, app and trust — for OpenAPI, Swagger,
GraphQL, MCP `tools/list`, and both A2A agent-card paths. `api.cloudexmachina.io` and
`mcp.cloudexmachina.io` do not resolve in DNS. `app.cloudexmachina.io` and
`docs.cloudexmachina.io` answer HTTP 200 with their own HTML shell for every path, which is a
soft-200, not a document.

The product is a per-tenant web application at `https://<tenant_id>.cloudexmachina.io`, entered
through SAML 2.0 single sign-on that Cloud ex Machina staff enable by hand.
